# 📊 Data Analytics - Ejercicios Prácticos

Repositorio con los ejercicios y proyectos desarrollados durante mi especialización en Análisis de Datos (IT Academy, Barcelona Activa, 2025-2026).

## 🛠️ Tecnologías cubiertas

- **SQL** — bases de datos relacionales, gestión de tablas, vistas y modelado
- **Power BI** — indicadores, dashboards e informes de visualización
- **Python** — fundamentos, análisis con Pandas y visualización de datos
- **APIs REST** — consumo de datos desde fuentes externas
- **MongoDB** — introducción a bases de datos no relacionales

## 📁 Estructura

Las carpetas están numeradas por orden de progresión técnica (no cronológico del curso):

| Carpeta | Contenido |
|---|---|
| `01-SQL-Basico` | Introducción a bases de datos relacionales |
| `02-SQL-Tablas-Vistas` | Gestión de tablas, índices y vistas |
| `03-SQL-Modelado` | Modelado de bases de datos SQL |
| `04-PowerBI-Practica-1` | Introducción e indicadores en Power BI |
| `05-PowerBI-Visualizaciones` | Visualizaciones e informes avanzados |
| `06-Python-Basico` | Fundamentos de Python |
| `07-Python-Pandas` | Análisis de datos con Pandas |
| `08-Python-Visualizacion` | Visualización de datos en Python |
| `09-API-REST` | Consumo de datos desde una API REST |
| `10-MongoDB` | Bases de datos no relacionales |
| `11-Proyecto-Final` | **Proyecto integrador** — caso práctico de análisis de negocio |

## ⭐ Proyecto destacado

El proyecto más completo de este repositorio es **`11-Proyecto-Final`**, donde se integran limpieza, análisis y visualización de datos en un caso práctico de negocio real.
